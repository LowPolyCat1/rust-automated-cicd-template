# Branch Naming

## Feature branches

Name a feature branch `feat/<feature>-<n>`. Use `<n>` for the position of the
branch in the stack.

## Non-feature branches

Name a non-feature branch with one of these prefixes:

- `fix/<name>` — a bug fix
- `ci/<name>` — a CI change
- `deps/<name>` — a dependency update
- `chores/<name>` — other maintenance
- `docs/<name>` — a documentation change
- `perf/<name>` — a performance improvement
- `ref/<name>` — a refactor with no behavior change
